════════════════════════════════════════════════════════════════
HOW THE GAME HANDLES MISSING FILES
════════════════════════════════════════════════════════════════

For each animation state the game checks in this order:

1. ember_idle.png    → Found? Use it.
2. ember_sheet.png   → Found? Use row 0 from sheet.
3. Not found?        → Use placeholder (auto-generated colored shape)

You do NOT need all files at once.
Add them one by one — the game uses what is available.
Missing states will show placeholder automatically.
